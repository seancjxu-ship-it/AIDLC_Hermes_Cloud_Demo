# Code Review / 代码评审

Check scope, behavior, backward compatibility, error handling, readability, and test coverage. Separate blocking findings from recommendations. Do not approve code when deterministic gates fail.

检查范围、行为、向后兼容性、异常处理、可读性和测试覆盖。区分阻断问题与改进建议；确定性门禁失败时不得批准代码。
