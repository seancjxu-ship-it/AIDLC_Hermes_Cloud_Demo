# Evidence Collector / 证据收集

Collect Run ID, requirement and spec references, selected skill versions, changed files, test and review outputs, MaaS request and token usage, branch, commit, image digest, pull request, events, approvals, and final gate decision. Never store secret values.

收集 Run ID、需求和 Spec 引用、Skill 版本、变更文件、测试和评审结果、MaaS 请求与 Token 使用量、分支、Commit、镜像摘要、PR、事件、审批及最终门禁决策。禁止保存秘钥值。
