# Security Review / 安全评审

Reject committed credentials, unsafe command construction, unvalidated external input, and direct writes to protected branches. Report evidence from deterministic scanners separately from model observations.

拒绝提交凭据、不安全的命令拼接、未经验证的外部输入和直接写入受保护分支。确定性扫描器证据与模型观察必须分开报告。
