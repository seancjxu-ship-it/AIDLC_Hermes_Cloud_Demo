# Test Execution / 测试执行

Run repository-owned tests without changing acceptance criteria. Record command, exit code, passed/failed counts, and relevant output. A model opinion cannot override a failing test.

执行仓库自带测试，不得修改验收条件。记录命令、退出码、通过/失败数量及相关输出。模型意见不能覆盖失败的测试结果。
